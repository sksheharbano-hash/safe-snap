# Sample Images

Place sample images here for testing and demonstration.

## Suggested samples

- `owner_solo.jpg` — A clear, front-facing single-person photo of the owner (for enrollment)
- `group_with_owner.jpg` — A group photo that includes the owner (to test preservation)
- `group_no_owner.jpg` — A group photo without the owner (all faces should be anonymized)
- `no_faces.jpg` — An image without any people (should produce "No faces detected")

## Privacy note

Do not commit real personal photos to a public repository.
Use consent-free stock photos for demonstration purposes.

Good sources:
- https://www.pexels.com (free stock photos)
- https://unsplash.com (free stock photos)
- https://generated.photos (AI-generated faces — no real people)
